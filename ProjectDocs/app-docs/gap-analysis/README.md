# Gap analysis: canvas YAML vs code app, 16 Admin/PM screens (19 Oct 2026)

These reports compare each screen's canvas YAML and Power Fx with `ProjectCosts-CodeApp/src/features/<phase>/<slug>/`. They were written read-only and checked against the canvas source. Each report contains:
- a requirements table (Data, Behaviour, State, UI), with each row marked COVERED, PARTIAL, MISSING or WRONG;
- proposed changes, split into UI, rules and hooks;
- open questions for the product owner.

The reports were written as of 19 Oct 2026, **before** any redevelopment. Re-check a report against the code before acting on it.

- Hidden controls and components: `node ProjectDocs/tools/canvas-hidden-controls.js ProjectDocs/_extracted/msapp/projectmanagement/Src`, or point it at the `Src/Components` folder.
