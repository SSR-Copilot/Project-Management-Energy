# ProjectCosts-CodeApp — changes 1.21.753 calls for (documented, NOT applied)

`ProjectCosts-CodeApp/` was deliberately left untouched in this pass (564 of 564 files
byte-identical to the input). This lists what the 1.21.753 solution means for it, file by file,
so it can be scheduled. Paths are under `ProjectCosts-CodeApp/src/`. Gap ids refer to
`ProjectDocs/migration-plans/10-solution-1.21.753-gap-register.md`.

## Required — behaviour differs from 1.21.753

### R1 · Italian price-zone names (G-07) — `features/periods/opexRules.ts:1129`

`ITALY_AREA_BY_REGION` still carries the 1.21.709 spellings. 1.21.753 `App.OnStart`
(`gblAreaWithRegion`) dropped the spaces:

| regions | today | 1.21.753 |
|---|---|---|
| Lazio, Abruzzo, Campania, Umbria | `"Italy_Centre - South"` | `"Italy_Centre-South"` |
| Marche, Toscana | `"Italy_Centre - North"` | `"Italy_Centre-North"` |

The map is the key into `Country Inflation Profiles`; with the old spelling an Italian project
in those six regions resolves to no profile once the data uses the new names. Change the six
values; update any test that pins the old strings; consider keeping the 1.21.709 map as
`ITALY_AREA_BY_REGION_CANVAS709` with a test, per the SOURCE DEFECT / twin convention.

### R2 · Capex `% Values` rounding (G-06) — `features/capex-costs/rules.ts:798`

`individualDistribution` uses `round(totalCostForPct * v / 100, 0)` for a percent scheme.
1.21.753 (`btn_Right_Panel_Add_Contract_Calculate_Allocated_Cost.OnSelect`,
`ico_Production_CardHeader_Up_3.OnSelect` and the panel Save) uses **`RoundDown`** — absolute
months stay `Round(v, 0)`; the conversion still applies only while `totalCostForPct <> 0`.

### R3 · Capex `% Values` remainder (G-06) — `features/capex-costs/rules.ts` `resolvedPayments`

Flooring every month leaves a shortfall. The 1.21.753 Save hands it to the **latest month
carrying a positive amount** (`SortByColumns(…, "Year", Descending, "MonthNo", Descending)`),
so the contract sums exactly to the typed Total Cost box (not `totalCostForPct`). Months at 0 or
blank never absorb. The skeleton's `absorbPercentRemainder` (capex `rules.ts`, UT-CAPEX-060) is a
drop-in reference.

### R4 · Percent mode on open (G-06) — where an existing contract's scheme becomes `"percent"`

`tmr_Capex_Cost_Cost_EnrichLoader.OnTimerEnd` now opens a contract in percent mode only when its
scheme is `% Values` **and** `Coalesce('Total Cost', 0) <> 0`; a `% Values` contract with no
total opens showing amounts. Find the mapping from `vsb_distributionscheme` to
`CostLine.distributionScheme` used when the edit panel opens and add the total test. Reference:
skeleton `enrichSchemeIsPercent` (UT-CAPEX-061).

## Accessibility identities (canvas `AccessibleLabel`)

The cost app sets `AccessibleLabel` on 41 distinct controls in 1.21.753. This app carries the
canvas name for **7** of them (Description, Total Cost, Start/End Date, Average Amount Per
Payment, Cluster 1, the loading spinner). Under this app's own convention
(`ProjectDocs/migration-plans/09-tosca-automation-conventions.md`: canvas name on `aria-label` *and*
`data-testid`), the other **34** have no identity:

| screen | controls without the canvas identity |
|---|---|
| Capex Costs | `tab_Costs_ContentAssignableAccountCategories`, `btn_Costs_ProjectCosts_TableCommandBar_AddCostFromTable`, `tgl_Costs_ProjectCostbtn_ShowEmptyAccounts`, `tgl_Costs_ProjectCostbtn_ShowPlannedPaid`, `drp_Costs_ProjectCostbtn_ShowCostPaidBy`, `drp_Costs_ProjectCostbtn_ShowSelectedYear`, `btn_Costs_ProjectCostbtn_ShowPreviousYear`, `btn_Costs_ProjectCostbtn_ShowNextYear`, `chk_AddContract_RightPanel_SelectCluster2_1` … `SelectCluster5_1`, `drp_Add_Edit_Cost_Data_RightPanel_Form_Link_to_Cluster`, `drp_AddContract_RightPanel_PaymentFrequency_1`, `txt_Costs_RightPanel_EditCostsInSubaccount_BodyContent_FirstMonth_24` … `_35` (the twelve month inputs) |
| Opex Costs | `drp_OpexCosts_RightPanel_NewEditCost_BodyContent_DurationYears`, `…_DurationMonths`, `…_DistributionFrequency_Month` |
| Land Lease Costs | `drp_LandLease_RightPanel_NewEditPeriod_BodyContent_DurationYears_1`, `…_DurationMonths_1`, `drp_LandLease_RightPanel_NewEditCost_BodyContent_DistributionFrequency_Month_1` |
| components | `cmp_PopUp_Loading_1.spi_PopUpLoading_Spinner_1`, `cmp_Information_Button_PCF.con_Information_ToolTip_Dismiss`, `cmp_Header.but_Main_Project_Overview_Header_Redirect_4` (hidden in the canvas — likely nothing to do) |

Two things to know before wiring them:

- **`btn_Costs_ProjectCostbtn_ShowNextYear`** has `Text: "Previous Year"` in the canvas (a
  copy-paste defect). Its AccessibleLabel is its own name, so the canvas-name convention is
  safe; do not copy its Text into a caption.
- **The two code bases now differ on `aria-label`.** The skeleton (`ProjectCosts-CodeApp/skeleton-reference`,
  14 Oct 2026 decision) renders the caption on `aria-label` and the canvas name on
  `data-testid`; this app renders the canvas name on both. Both carry the same
  `data-testid`, so Tosca modules keyed on `data-testid` work against either. If the
  conventions should converge, the skeleton's generated corpus and gate
  (`scripts/extract-accessible-labels.mjs`, `scripts/check-a11y.mjs`, `src/a11y/`) can be
  ported here; only the caption rule would differ.
