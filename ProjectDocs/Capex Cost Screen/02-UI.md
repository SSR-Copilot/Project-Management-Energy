## 2. Canvas implementation

### 2.1 Resolved globals and the authoring size

`App.OnStart` (`App.pa.yaml:205`) sets:

```powerfx
Set(gblAppSizes, {
    Padding: {Page: 0},
    Form: { X: 20, Space: 20, Label200Width: 150, LabelBeforeHeight: 52, LabelBeforeHeightErr: 42 },
    Font: { ExtraExtraSmall: 8, ExtraSmall: 9, Small: 10, Medium: 11, Large: 12, ExtraLarge: 14, ExtraExtraLarge: 16 },
    LeftNavigation: { ExpandedWidth: 200, DecreasedWidth: 32 },
    Position: { X: 20, Y: 2 },
    RightPanel: { MinWidth: 450, Top: 20, Left: 20, Right: 20 }
});
Set(gblLeftNavigationMenuIsExpanded, true);
```

Values used below:
- `gblAppSizes.Padding.Page` = **0**;
- `Position.X` = **20**;
- `Form.Label200Width` = **150**;
- `LabelBeforeHeight` = **52**;
- `LabelBeforeHeightErr` = **42**;
- `LeftNavigation` = **200 / 32**.

`RightPanel.MinWidth` appears only in a commented-out formula (not live), at L10281.

The app is authored at **1366 × 768** with `DocumentLayoutScaleToFit: false` (`Properties.json`),
so containers stretch with the window rather than scaling. The screen itself sets
`Fill: =gblAppStyles.Screen.Fill` (L12), whose colour is in 03, and
`LoadingSpinner: =LoadingSpinner.Data` (L13).

Arithmetic at the 1366 × 768 design size is marked "(inferred)" where it is computed rather than
read.

gives six tabs: DEVEX/CAPEX Summary, Wind Turbine / Panels, Development Expenses, Construction
Expenses, Substation / Grid Connection, Other CAPEX.

**Which tab is selected on open.** `OnVisible` (L257-276) is commented "Select real CAPEX
category, not DEVEX/CAPEX Summary". It sets `locSelectedCapexAccountCategory` to the current
real category, if one is held, or else to the **first real category**:
`First(SortByColumns(Filter(colCapexAccountCategoriesNew, !IsBlank('CAPEX Account List') && Not(Name = "Overleveraging")), "vsb_order", SortOrder.Ascending))`.
It then runs `Reset(tab_Costs_ContentAssignableAccountCategories)` (L284). So on a visit the grid
tab is shown, not the Summary.

The landing screenshot shows the Summary selected, which may be a later click; see §5.

**The tab switches the region below.** It is the only switch between the two content regions:
